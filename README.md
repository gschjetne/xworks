# xWorks

xWorks (code name) is an office suite built from scratch to be usable, fast and correct.
It covers word processing, spreadsheets, presentations, Lotus Improv-style
multidimensional modeling and office databases, in one application with
one file format.

## Status

Designing. The architecture and the tracks of work are approved; the next
step is planning M1, the walking skeleton.
