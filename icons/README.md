# Icons

The interface's icons are [Lucide](https://lucide.dev)'s, chosen by the
project owner in review frhewnk0 (2026-10-22). They're under the ISC
licence, in [lucide/LICENSE](lucide/LICENSE), and committed here as
Lucide's release 1.61.0 has them, unchanged, from
`https://raw.githubusercontent.com/lucide-icons/lucide/1.61.0/icons/NAME.svg`.

`toolkit::Icon` reads them and draws them as fills. Add one by copying its
file from that release; a test reads and draws every file here.
